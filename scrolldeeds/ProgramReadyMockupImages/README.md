# Program-ready paywall mockups

Drop your custom screenshots here. They show inside the iPhone frames on the compact paywall.

## File names

- `ProgramReadyMockup1.png`
- `ProgramReadyMockup2.png`
- `ProgramReadyMockup3.png`
- `ProgramReadyMockup4.png`
- `ProgramReadyMockup5.png` (optional)

Localized (used when that language is selected):

- `ProgramReadyMockup1_nl.png`
- `ProgramReadyMockup1_en.png`
- …same for `es`, `de`, `fr`, `ru`, `ar`

Also works: `.jpg`, `.jpeg`, `.heic`, `.webp`.

## Tips

- Portrait screenshots, about iPhone screen ratio (no extra device frame — the app already draws the iPhone mockup).
- If none of these files exist yet, the paywall falls back to the Quick Guide images.

## Fallback order

1. `ProgramReadyMockupX_<language>`
2. `ProgramReadyMockupX`
3. Quick Guide pages
