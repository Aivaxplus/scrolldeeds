## 🎯 Wat is ASO?

**ASO = App Store Optimization**

Het optimaliseren van je app listing zodat:
- ✅ Meer mensen je app vinden via zoeken
- ✅ Hogere rankings in de App Store
- ✅ Meer downloads = meer revenue

**Belangrijkste elementen:**
1. **Keywords** (100 karakters max) - Meest belangrijk!
2. **App Name** (30 karakters max)
3. **Subtitle** (30 karakters max)
4. **Description** (4000 karakters max)
5. **Screenshots** (visueel)
6. **App Icon** (eerste indruk)

## 📍 Waar invullen?

### **Stap 1: Ga naar App Store Connect**

1. **Open:** https://appstoreconnect.apple.com
2. **Login** met je Apple Developer account
3. **Klik:** "My Apps"
4. **Selecteer:** "ScrollDeeds"
5. **Klik:** "App Store" (links menu)
6. **Kies:** "1.0 Prepare for Submission" (of je versie)

### **Stap 2: Keywords invullen**

**Locatie:**
- Scroll naar beneden naar **"App Information"**
- Klik op **"App Information"** (of "App Store Information")
- Zoek naar **"Keywords"** veld
- **Max 100 karakters** (inclusief komma's en spaties!)

**Format:**
```
keyword1,keyword2,keyword3,keyword4
```
**Geen spaties na komma's!** (spaart karakters)

**Voorbeeld:**
```
dhikr,mindfulness,screen time,app lock,islamic,productivity,focus,phone addiction
```

### **Stap 3: Andere velden**

#### **App Name** (30 karakters max)
```
ScrollDeeds
```
*(Dit is je app naam, kan niet vaak veranderd worden)*

#### **Subtitle** (30 karakters max)
```
Mindful Screen Time
```
of
```
Break Phone Addiction
```

#### **Description** (4000 karakters max)
*(Zie hieronder voor complete description)*

## 🔍 Keywords vinden - Stap voor Stap

### **Methode 1: Competitor Analysis (Beste methode!)**

Zoek in de App Store naar:
- "screen time"

**Doe dit voor:**
- "dhikr"
- "islamic"

**Schrijf alle suggesties op!**

## 📊 Keyword Prioritering

### **Hoe kies je de beste keywords?**

**Formule:**
```
Score = (Search Volume × Relevance) / Competition
```

**Voor ScrollDeeds:**

| Keyword | Search Volume | Relevance | Competition | Score | Prioriteit |
|---------|--------------|-----------|-------------|-------|------------|
| dhikr | Laag | ⭐⭐⭐⭐⭐ | Laag | ⭐⭐⭐⭐⭐ | **1. Hoogste** |
| screen time | Hoog | ⭐⭐⭐⭐ | Hoog | ⭐⭐⭐ | 2. Hoog |
| mindfulness | Hoog | ⭐⭐⭐⭐ | Medium | ⭐⭐⭐⭐ | 2. Hoog |
| app lock | Medium | ⭐⭐⭐⭐⭐ | Medium | ⭐⭐⭐⭐ | 2. Hoog |
| islamic | Medium | ⭐⭐⭐⭐⭐ | Laag | ⭐⭐⭐⭐⭐ | **1. Hoogste** |
| productivity | Hoog | ⭐⭐⭐ | Hoog | ⭐⭐ | 3. Medium |
| phone addiction | Medium | ⭐⭐⭐⭐ | Medium | ⭐⭐⭐ | 3. Medium |

**💡 Strategie:**
1. **Start met unieke keywords** (dhikr, islamic) = minder concurrentie
2. **Voeg brede keywords toe** (screen time, mindfulness) = meer volume
3. **Balanceer** tussen volume en concurrentie

## ✅ Best Practices

### **1. Keywords Veld (100 karakters max)**

**✅ DO:**
- Gebruik komma's zonder spaties: `dhikr,mindfulness,screen time`
- Start met meest relevante keywords
- Gebruik variaties: `dhikr,zikr,remembrance` (allemaal hetzelfde!)
- Test verschillende combinaties

**❌ DON'T:**
- Geen spaties na komma's: `dhikr, mindfulness` ❌
- Geen app naam: `ScrollDeeds` ❌ (gebruik je al in app name!)
- Geen generieke woorden: `app,free,new` ❌
- Geen duplicaten: `dhikr,dhikr app` ❌

**Voorbeeld (99 karakters):**
```
dhikr,mindfulness,screen time,app lock,islamic,productivity,focus,phone addiction,self-control,spiritual
```

## 🔄 A/B Testing Keywords

### **Hoe test je keywords?**

1. **Start met Keyword Set A:**
   ```
   dhikr,mindfulness,screen time,app lock,islamic,productivity
   ```

2. **Wacht 2-4 weken**
   - Check App Store Connect → Analytics
   - Zie hoeveel downloads via "App Store Search"

3. **Test Keyword Set B:**
   ```
   dhikr,islamic,mindfulness,phone addiction,app blocker,productivity
   ```

4. **Vergelijk:**
   - Welke set geeft meer downloads?
   - Welke keywords werken het beste?

5. **Optimaliseer:**
   - Houd keywords die werken
   - Vervang keywords die niet werken

**💡 Tip:** Test 1 keyword per keer voor beste resultaten!

## 📈 Monitoring & Analytics

### **App Store Connect Analytics**

**Waar te vinden:**
1. App Store Connect → ScrollDeeds
2. Klik "Analytics" (links menu)
3. Klik "App Store Search"

**Wat te checken:**
- **Impressions:** Hoe vaak wordt je app getoond in zoekresultaten?
- **Product Page Views:** Hoeveel mensen klikken op je app?
- **Downloads:** Hoeveel downloads via zoeken?

**Keywords die werken:**
- Hoge impressions + hoge conversion = **Goede keyword!**
- Hoge impressions + lage conversion = **Verander keyword!**
