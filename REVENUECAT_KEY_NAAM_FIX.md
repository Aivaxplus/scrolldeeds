# Key Naam Error Oplossen

## ⚠️ Error: "Key name must begin with subscription..."

Apple vereist dat subscription keys beginnen met "subscription".

---

## ✅ Oplossing

### Stap 1: Pas Key Naam Aan

1. **Ga terug naar het Key Name veld**
2. **Type:**
   ```
   subscription_revenuecat
   ```
   Of:
   ```
   subscription_revenuecat_key
   ```
   Of:
   ```
   subscription_scrolldeeds
   ```

3. **⚠️ BELANGRIJK:**
   - Moet beginnen met `subscription_`
   - Geen hoofdletters (of alleen eerste letter)
   - Geen speciale karakters behalve `_`

---

### Stap 2: Probeer Opnieuw

1. **Key Name:** `subscription_revenuecat`
2. **Key Usage Description:** (optioneel) `For RevenueCat subscription management`
3. **DeviceCheck:** Aangevinkt (zoals je al had)
4. **Klik "Continue"**

---

## 📋 Goede Key Namen Voorbeelden

✅ **Goed:**
- `subscription_revenuecat`
- `subscription_revenuecat_key`
- `subscription_scrolldeeds`
- `subscription_key`

❌ **Fout:**
- `RevenueCatKey` (geen subscription_ prefix)
- `RevenueCat Subscription Key` (geen subscription_ prefix)
- `subscription RevenueCat` (spatie in plaats van _)

---

## 🔍 Als Error Blijft

### Check:

1. **Begint met `subscription_`?**
   - ✅ Ja: `subscription_revenuecat`
   - ❌ Nee: `RevenueCatKey`

2. **Geen hoofdletters?**
   - ✅ Goed: `subscription_revenuecat`
   - ⚠️ Kan: `Subscription_revenuecat` (maar kleine letters is beter)

3. **Geen speciale karakters?**
   - ✅ Goed: `subscription_revenuecat`
   - ❌ Fout: `subscription-revenuecat` (gebruik _ niet -)

---

## ✅ Stap-voor-stap

1. **Type in Key Name veld:**
   ```
   subscription_revenuecat
   ```

2. **Druk op Enter of klik buiten veld**

3. **Check of naam zichtbaar is**

4. **Klik "Continue"**

5. **Download P8 key**

6. **Noteer Key ID en Issuer ID**

7. **Upload in RevenueCat**

---

**Probeer `subscription_revenuecat` als key naam en laat weten of het werkt!** 🚀
