§# Issuer ID Niet Zichtbaar? Alternatieve Manieren

## 🔍 Als Issuer ID Niet Boven Keys Staat

Soms staat Issuer ID niet direct zichtbaar. Hier zijn alternatieve manieren:

---

## ✅ Methode 1: Via App Store Connect

### Stap 1: Ga naar App Store Connect

1. **Open:** [appstoreconnect.apple.com](https://appstoreconnect.apple.com)
2. **Login** met je Apple Developer account

### Stap 2: Ga naar Users and Access

1. **Klik op je naam** (rechtsboven)
2. **Selecteer:** "Users and Access"

### Stap 3: Ga naar Keys Tab

1. **Klik op tab:** "Keys" (naast People, Sandbox, etc.)
2. **Bovenaan de pagina zie je:**
   - **Issuer ID:** `XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX`
   - Dit is je Issuer ID!

---

## ✅ Methode 2: Via API Key Details

### Stap 1: Klik op Je Key

1. **In Apple Developer → Keys**
2. **Klik op je key:** `RevenueCatSubscription` (of de naam van je key)
3. **Je ziet key details**

### Stap 2: Check Key Details Pagina

1. **Op de key details pagina:**
   - Soms staat Issuer ID hier
   - Check alle tekst op de pagina

---

## ✅ Methode 3: Via Directe API Link

### Stap 1: Probeer Deze Link

```
https://appstoreconnect.apple.com/access/api
```

1. **Login** als je nog niet ingelogd bent
2. **Je zou Issuer ID moeten zien**

---

## ✅ Methode 4: Check in RevenueCat (Als Je Het Al Eens Ingevuld Hebt)

### Als je Issuer ID al eerder in RevenueCat hebt ingevuld:

1. **Ga naar RevenueCat Dashboard**
2. **Apps & providers** → Je app
3. **Check het Issuer ID veld**
4. **Het staat daar al ingevuld!**

---

## ✅ Methode 5: Via Apple Developer Account Info

### Stap 1: Ga naar Account

1. **Apple Developer Portal**
2. **Klik op je naam** (rechtsboven)
3. **Selecteer:** "Account" of "Preferences"

### Stap 2: Check Account Details

1. **Zoek naar:** "Issuer ID" of "Team ID"
2. **Soms staat het hier**

---

## ✅ Methode 6: Contact Apple Support

Als je het echt niet kunt vinden:

1. **Contact Apple Developer Support**
2. **Vraag om je Issuer ID**
3. **Ze kunnen het voor je opzoeken**

---

## 🔍 Wat Is Issuer ID?

- **Format:** UUID met streepjes
- **Voorbeeld:** `57246542-96fe-1a63-e053-0824d0110`
- **Lengte:** 36 karakters (inclusief streepjes)
- **Hetzelfde voor alle keys** in je account

---

## ⚠️ Belangrijk

**Issuer ID is hetzelfde voor alle keys in je Apple Developer account!**

Als je het eenmaal hebt, hoef je het niet opnieuw te zoeken.

---

## 📋 Probeer Deze Volgorde

1. ✅ **App Store Connect** → Users and Access → Keys tab
2. ✅ **Directe link:** `https://appstoreconnect.apple.com/access/api`
3. ✅ **RevenueCat** (als je het al eerder hebt ingevuld)
4. ✅ **Apple Developer** → Account → Preferences

---

## 🆘 Als Niets Werkt

### Check:

1. **Heb je toegang tot Keys?**
   - Je moet Account Holder of Admin zijn

2. **Probeer een andere browser:**
   - Chrome
   - Safari
   - Firefox

3. **Clear cache en cookies:**
   - Soms helpt dit

4. **Contact Apple Support:**
   - Ze kunnen je Issuer ID geven

---

**Probeer eerst App Store Connect → Users and Access → Keys tab!** 🚀
